# JARVIS

Electron 기반 개인용 AI 비서입니다. 음성·텍스트 대화, PC 제어, 대시보드, 3D CAD 화면, 모바일 접속 기능이 포함되어 있습니다.

## Windows EXE 빌드

Windows PC에서 Node.js를 설치한 뒤 프로젝트 폴더에서 실행합니다.

```powershell
npm ci
npm run build:exe
```

설치 파일은 `dist/`에 생성됩니다.

## 마이크 설정과 확인

1. Windows **설정 → 개인정보 및 보안 → 마이크**에서 **마이크 액세스**와 **데스크톱 앱의 마이크 액세스**를 켭니다.
2. JARVIS에서 **관리창 → 보이스 설정 → 입력 마이크**를 열고 사용할 장치를 선택합니다. 장치가 보이지 않으면 **새로고침**을 누릅니다.
3. **입력 테스트**를 누른 뒤 2~3초 동안 말합니다. 입력 레벨이 표시되면 앱이 해당 마이크의 소리를 받고 있는 것입니다.
4. 음성 명령을 인식하려면 **관리창 → AI 두뇌 설정**에서 Gemini API 키를 저장하고 인터넷 연결을 확인합니다. 입력 테스트는 API 키 없이도 사용할 수 있습니다.

마이크가 연결되지 않거나 권한이 없으면 보이스 설정에 오류 원인이 표시됩니다. 장치 선택은 다음 실행에도 유지됩니다. EXE에서 저장한 API 키와 기타 설정은 설치 폴더가 아닌 사용자 설정 폴더에 보관됩니다.

## 최근 변경: Windows EXE 마이크 입력 수정

- 작은 Electron 창을 모바일 화면으로 오인해 자동 음성 대기가 시작되지 않거나 모바일 PWA 캐시가 등록되던 문제를 수정했습니다.
- 실행할 때 저장된 마이크 선택을 지우던 동작과 특정 오디오 인터페이스를 강제로 우선 선택하던 동작을 제거했습니다.
- 보이스 설정에 마이크 선택, 장치 목록 새로고침, 입력 레벨 테스트를 추가했습니다. 선택한 장치를 녹음에도 적용합니다.
- 별도 Chrome 음성 인식 창을 실행하지 않고 Electron에서 선택한 마이크로 녹음하도록 변경했습니다.
- API 키 누락이나 음성 인식 서비스 연결 실패가 화면에 표시되도록 했습니다.
- EXE에서 API 키 설정이 읽기 전용 앱 패키지에 저장되지 않던 문제를 수정했습니다.

코드 문법 검사는 통과했습니다. Windows EXE의 실제 마이크 동작은 Windows PC에서 위 절차로 확인해야 합니다.
